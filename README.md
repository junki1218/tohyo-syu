# とうひょうアプリ

知的障害のある子どもが自分で操作できる投票アプリ。HTML / CSS / JavaScript だけで動き、
サーバ側の処理も外部通信もない。子機で投票 → QRコードで結果を出力 → 親機がQRを読んで合計、という流れ。

対象端末は **iPad（Safari）横向き**。

---

## ファイル構成

```
投票アプリ/
├ index.html          全画面の HTML
├ css/style.css       見た目
├ fonts/              丸ゴシック(M PLUS Rounded 1c をサブセット化・約130KB)
├ ICON/               はじめから入っている5枚の絵(長辺768px・合計約570KB)
├ ICON_original/      上の元データ(長辺1024px・合計約3.8MB)。使っていないので消してよい
├ js/
│  ├ store.js         設定(localStorage)と画像(IndexedDB)の保存
│  ├ sound.js         効果音(WebAudioで合成。音源ファイル不要)
│  ├ fx.js            紙ふぶき(1票入ったとき・1位の発表だけ)
│  ├ qr.js            QRの生成・読み取り・コード文字列の変換
│  ├ result.js        棒グラフと結果発表
│  ├ vote.js          投票画面(長押し判定)
│  ├ parent.js        親機モード
│  ├ settings.js      設定画面
│  └ app.js           画面遷移と全体の流れ
└ vendor/
   ├ qrcode.js        QR生成 (qrcode-generator, MIT)
   └ jsQR.js          QR読み取り (jsQR, Apache-2.0)
```

外部CDNは使っていないので、**オフラインでも全機能が動く**（カメラを除く。下記参照）。
書体もアプリの中に同梱しているため、どの端末でも同じ丸ゴシックで表示される。
ライセンスは `fonts/LICENSE.txt`（SIL Open Font License 1.1）。

## 使いかた

### 開きかた（重要）

**ローカルサーバか https で開くこと。** `index.html` をダブルクリックして `file://` で開くと、
iPad Safari では画像の保存（IndexedDB）もカメラも使えない。起動時に警告が出る。

PC でローカルサーバを立てる例（このフォルダで実行）:

```bash
python -m http.server 8765
```

同じ Wi-Fi の iPad から `http://<PCのIPアドレス>:8765/` で開く。
（カメラは `https` か `localhost` でしか動かないため、iPad からカメラを使いたい場合は
GitHub Pages などの https に置くのが確実。カメラが使えなくても手入力で運用できる。）

### 1. せってい

| 項目 | 内容 |
|---|---|
| がぞう | 2〜5枚（**既定 5枚**）。**はじめから `ICON/` の5枚が入っている**。枠を押すと自分の写真に
  差し替えられ、長辺1024pxに縮小して端末内に保存される。差し替えたものは「もどす」で元の絵に戻る |
| なまえ | 絵の下に出す文字。枠の下の入力欄で書き換えられる。既定は下表のとおり |
| とうひょうすう | **クラス全員ぶんの合計票数（既定 28）**。この数だけタッチすると自動で締め切られる。1〜40 |
| けっかはっぴょうモード | ON=最下位から1つずつ、先生のタップで発表。OFF=全部いっぺんに表示 |
| ばんごう | 画像に 1〜5 のバッジを出す |
| こうかおん | 長押し中の上昇音と、入ったときの音 |
| ながおしの ながさ | みじかい(0.7秒) / ふつう(1.2秒) / ながい(2.0秒) |
| とんとん の かいすう | 連打で1票入れるのに必要な回数。5 / 10 / 15 / 20（既定 10） |
| たんまつの ばんごう | 自動生成される2文字。親機での重複チェックに使う |

はじめから入っている5枚と、その名前：

| 番号 | 絵 | なまえ |
|---|---|---|
| 1 | `ICON/03_platform_wait_boy.png` | しんかんせん |
| 2 | `ICON/17_itadakimasu_boy.png` | ごはん |
| 3 | `ICON/26_skytree_observe_lookdown_boy.png` | スカイツリー |
| 4 | `ICON/38_sleep_girl.png` | おとまり |
| 5 | `ICON/44_aquarium_tunnel_boy.png` | アクアパーク |

名前は **投票画面の絵の下・1票入ったときの画面・結果のグラフ・QR画面** に出る。

### 2. とうひょう（つうじょうモード）

- 端末を回して、1人ずつ操作する。1票を入れる方法は **2とおり。どちらでもよく、混ぜてもよい**。
  - **ながおし**：写真を押しつづける。設定した秒数（既定1.2秒）でたまる。
  - **とんとん**：細かく連打する。設定した回数（既定10回）でたまる。
    軽く触れただけの一瞬のタッチでも、1回ぶんは必ずカウントされる。
- どちらも同じ「ためゲージ」を動かしている。押している間は白いリングが時計回りに満ちていき、
  指を離しているときは「あと ○ かい」と残りの連打回数が出る。
- **手を止めて約3秒さわらないと、ゲージはゆっくり0に戻る**（置きっぱなしで勝手に入らないように）。
- **ちがう写真に移ると、ためていたぶんは捨てられる**（迷って行き来しても誤って入らない）。
- 確定すると「はいりました！」が全画面で出る。
- 画面に出るのは「あと ○にん」と残り票の●だけ。**各画像の得票は投票中は見せない**
  （途中経過が見えると多い方に票が寄るため）。
- 設定した票数に達すると自動で終了画面へ。
- 左上の ✕ は **1.5秒長押し** で中断（誤操作防止）。
- 途中でリロードや離脱をしても票は残っていて、次に開いたときに「つづきから」を聞かれる。

### 3. けっかはっぴょう

- 発表モードONなら、**最下位から**1つずつ。「はっぴょう する」を押すたびに次の棒がゆっくり伸びる。
- 最後（1位）はファンファーレと👑。
- 発表が終わると「QRコードを だす」が出る。

### 4. QRコード

- QRの中身は `V1.7K.3-1-4-2-5` の形。`7K`=端末番号、`3-1-4-2-5`=1〜5番の得票数。
- QRの下に **てにゅうりょくコード**（`7K 3-1-4-2-5`）も出る。カメラが使えないときはこれを親機に打ち込む。

### 5. おやきモード

- 子機のQRを読み込んでためていく。**台数は決めず、先生が「これで しゅうけい する」で締める。**
- 読み取り手段は3つ:
  1. **カメラ**（https / localhost のときだけ）
  2. **がぞうファイル**（子機のQRをスクショして送る）
  3. **てにゅうりょく**（`7K 3-1-4-2-5` / `7K,3,1,4,2,5` / 全角でも可）
- 同じ端末番号を2回読むと警告が出て、二重計上されない。
- 読み取り一覧は端末内に保存されるので、途中で画面を閉じても消えない。
- 「しゅうけい する」で合計を出し、同じ棒グラフで発表する（親機では QRは出ない）。

---

### 既定値

はじめて開いたときは **がぞう5枚・28とうひょう**、けっかはっぴょうモードON、ながおし1.2秒、とんとん10回。
一度でも開いた端末は設定が保存されているので、既定値を変えても反映されない。
その端末では設定画面で直すか、いちばん下の「がぞうと せっていを すべて けす」を押す。

## 仕様のメモ

- **投票の型**: クラス全員ぶんの合計票数。誰が押したかは記録しない（秘密投票）。
- **誤タッチ対策**: ながおし／とんとん のどちらかで「ためきる」まで入らない。
  1回さわっただけでは入らず、手を止めれば約3秒で戻る。
- **保存先**: 設定は `localStorage`、画像は `IndexedDB`。どちらも端末内のみ。外部送信は一切なし。
- **データを消す**: 設定画面いちばん下の「がぞうと せっていを すべて けす」。
  取り込んだ写真と名前が消え、`ICON/` の既定の絵と名前に戻る。
- **`ICON/` の画像は 長辺768px・1枚 85〜141KB（合計約570KB）**。
  元データ（長辺1024px・合計約3.8MB）は `ICON_original/` に置いてある。アプリは見ていないので、
  表示を確かめて問題なければ フォルダごと消してよい。
- 絵を差し替えるときは **`ICON/` の中のファイル名をそのままにして** 上書きする。
  読み込みに失敗したときは自動で2回まで読み直す。

## 動かなかったときは

| 症状 | 原因と対処 |
|---|---|
| 画像が次回に残らない | `file://` で開いている。ローカルサーバか https で開く |
| 絵が出ない枠がある | 簡易サーバが同時配信でこけていることがある。開き直すと直る（自動で2回まで再取得する） |
| カメラが開かない | 同上。`https` か `localhost` が必要。手入力かがぞうファイルで代用 |
| 音が鳴らない | iPad は最初のタッチまで音を出せない。1回どこかを押せば鳴る。設定の「こうかおん」も確認 |
| 縦向きで「よこむきにしてください」が出る | 端末を横にする（横向き前提のレイアウト） |
